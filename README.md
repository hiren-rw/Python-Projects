# 🚀 Fundamental Booster

A simple Python project that demonstrates the fundamentals of **user
input, data types, variables, operators, type casting, and built-in
functions**.

## 🎯 Objective

Build an interactive Personal Data Collector that: - Collects the user's
**name, age, height, and favorite number** - Processes and displays the
collected information - Demonstrates `print()` and `input()` - Uses
`int()`, `float()`, `type()`, and `id()` - Calculates an estimated
**birth year** using arithmetic operators

## 🛠️ Concepts Covered

-   🖨️ `print()` and `input()`
-   📦 Variables and data types
-   🔄 Type casting
-   ➕ Arithmetic operators
-   🔍 `type()` and `id()`
-   🧮 Basic data processing
