## 🎯 PROJECT MISSION

> **Practice Python control structures by building a menu-driven program.**

**Pattern Generator & Number Analyzer** is a console-based Python project that demonstrates pattern generation using nested loops and analyzes a user-defined range of numbers.

---

## ✨ FEATURES

| 🧩 Feature | 📌 Description |
|---|---|
| ⭐ Pattern Generator | Creates a right-angled star triangle |
| 🔢 Number Analyzer | Analyzes numbers within a selected range |
| 🟢 Odd / Even Check | Identifies whether each number is odd or even |
| ➕ Range Sum | Calculates the sum of all numbers |
| 📋 Menu System | Allows repeated operations until exit |
| 🔄 Control Flow | Uses loops, conditions, and `break` |

---

## 🖥️ HOW IT WORKS

```text
👋 Start
   │
   ▼
📋 Display Menu
   │
   ├── ⭐ Generate Pattern
   │       └── Create star triangle using nested loops
   │
   ├── 🔢 Analyze Number Range
   │       ├── Check Odd / Even
   │       └── Calculate Sum
   │
   └── 🚪 Exit
```
